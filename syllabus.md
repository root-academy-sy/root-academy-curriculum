## Weekly breakdown

### Week 1 — Python Foundations for Data Science
- **Learning objectives:**
  - *e.g. Understand Python syntax, variables, data types*
  - *e.g. Work with lists, dictionaries, and control flow*
  - *e.g. Read and manipulate tabular data with pandas basics*
- **Case study:** Employee Performance Analysis
- **Deliverables:** Lab + Assignment (see [week-01-python-foundations/](week-01-python-foundations/))

### Week 2 — NumPy and Pandas
- **Learning objectives:**
  - Explain why NumPy and Pandas are useful in data science
  - Create and use NumPy arrays for numerical data
  - Load a CSV into a Pandas DataFrame and inspect it
  - Select columns, filter rows, handle missing values and duplicates
  - Create new columns and summarize data with grouping
- **Case study:** Cleaning Employee Scores
- **Deliverables:** Lab + Assignment (see [week-02-numpy-pandas/](week-02-numpy-pandas/))

### Week 3 — Data Cleaning and Exploratory Data Analysis
- **Learning objectives:**
  - Understand the purpose of exploratory data analysis (EDA)
  - Identify and fix common data quality problems (missing values, duplicates, inconsistent categories, wrong types)
  - Ask and answer analytical questions using Pandas
  - Write clear notes explaining each cleaning/analysis step
- **Case study:** Employee EDA — this dataset and its cleaned output carry forward as the running example through Week 8
- **Deliverables:** Lab + Assignment (see [week-03-data-cleaning-eda/](week-03-data-cleaning-eda/))

### Week 4 — Data Visualization with Matplotlib and Seaborn
- **Learning objectives:**
  - Choose the right chart type for a given question
  - Create bar charts, histograms, box plots, and scatter plots
  - Use Matplotlib and Seaborn together
  - Write clear, honest interpretations of charts
- **Case study:** Visual report on the Week 3 employee dataset
- **Deliverables:** Lab + Assignment (see [week-04-data-visualization/](week-04-data-visualization/))

### Week 5 — Statistics Foundations
- **Learning objectives:**
  - Calculate descriptive statistics (mean, median, range, standard deviation)
  - Compare groups using summary statistics
  - Interpret correlation without confusing it with causation
  - Write statistical findings in plain language
- **Case study:** Statistical analysis of the employee dataset
- **Deliverables:** Lab + Assignment (see [week-05-statistics-foundations/](week-05-statistics-foundations/))

### Week 6 — Machine Learning: Regression
- **Learning objectives:**
  - Understand features, targets, and train/test splits
  - Train a `LinearRegression` model
  - Evaluate with MAE, MSE, and R2
- **Case study:** Predicting employee score from attendance/salary
- **Deliverables:** Lab + Assignment (see [week-06-regression/](week-06-regression/))

### Week 7 — Classification & Model Evaluation
*(Combined — the two lightest weeks of the original 10-week plan)*
- **Learning objectives:**
  - Train a classification model (`DecisionTreeClassifier`)
  - Evaluate with accuracy, confusion matrix, and classification report
  - Compare multiple models on the same data and interpret the differences
- **Case study:** Classifying high performers; comparing Logistic Regression vs Decision Tree
- **Deliverables:** Lab + Assignment (see [week-07-classification-model-evaluation/](week-07-classification-model-evaluation/))

### Week 8 — Capstone Project & Presentation
*(Combined wrap-up — capstone work has been building since Week 3)*
- **Learning objectives:**
  - Combine cleaning, EDA, visualization, statistics, and (optionally) a model into one end-to-end project
  - Present findings clearly: problem, dataset, cleaning, findings, conclusion
- **Case study / capstone project:** Student's own project (or the running employee dataset)
- **Deliverables:** Lab + Assignment (see [week-08-capstone/](week-08-capstone/))
