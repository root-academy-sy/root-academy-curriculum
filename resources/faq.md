# FAQ

**Do I need prior programming experience?**
No. Week 1 starts from Python basics, assuming no prior experience.

**Should I use Google Colab or VS Code?**
Start with **Colab** — no installation, works in your browser, and opens the
course notebooks directly from GitHub. Switch to a local **VS Code** setup
once you're comfortable and want a more professional workflow (this is also
what Root Academy's next-level course assumes). See
[`setup-guide.md`](setup-guide.md) for both options.

**Should I use Jupyter Notebook or a plain Python script?**
Labs and assignments are provided as Jupyter notebooks (`.ipynb`) so you can
see your code and outputs together. You're free to work in `.py` scripts
instead if you prefer, but notebooks are recommended.

**Where do I find the solutions?**
Each lab/assignment has a matching `*-solution.ipynb` file. Try the exercise
yourself first — you'll learn more by struggling a bit before checking the
answer.
