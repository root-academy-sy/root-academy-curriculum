# Week 8 — Capstone Project & Presentation

**Course:** Introduction to Data Science
**Week Topic:** Build, Present, and Wrap Up Your End-to-End Project

Your capstone shouldn't come as a surprise this week — you've been building
pieces of it since Week 3 (EDA on your chosen dataset), Week 4 (its visual
report), Week 5 (its statistics), and Weeks 6-7 (a model, if your project
calls for one). This week is about pulling those pieces into one coherent
project, and then presenting it clearly.

# Part 1: Capstone Project Work

## Main Goal

This is a guided project week. Combine the course skills into one beginner-friendly data science project: data loading, cleaning, EDA, visualization, basic statistics, and optional simple machine learning.

## Project Structure

- Problem statement
- Dataset description
- Data cleaning
- EDA questions
- Visualizations
- Basic statistics
- Optional simple ML model
- Conclusion

## Recommended Project Ideas

- Employee performance analysis
- Student grades analysis
- Sales analysis
- Customer activity analysis

## Next Level Preview

In the paid course, capstones will become portfolio-level projects with stronger datasets, project folders, dashboards, and deeper feedback.

# Part 2: Presentations and Wrap-up

## Main Goal

Present your project clearly. The focus is communication: explaining the question, showing the analysis, presenting visuals, and stating practical conclusions.

## Presentation Structure

- Project title
- Problem statement
- Dataset overview
- Cleaning summary
- Main findings
- Charts
- Optional model result
- Conclusion and next steps

## Course Wrap-up

Students should leave with a beginner portfolio piece and a clear understanding of what they can learn next.
